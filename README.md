# VK Feed Parser

Сбор постов VK по хештегам за нужный период → Excel.
Сразу несколько аккаунтов, капча пережидается отлёжкой, прерванный сбор продолжается
с того же места.

Всё управление — панель в браузере (доступна только с этого компьютера):
**http://127.0.0.1:8787**

---

## 1. Установка

Нужен Python **3.11 или 3.12** — https://www.python.org/downloads/
(на Windows при установке отметьте галочку **«Add python.exe to PATH»**).
Библиотеки и браузер Chromium панель поставит сама при первом запуске.

### macOS

1. Поставьте Python 3.11 или 3.12 с сайта выше (системный `python3` тоже подойдёт,
   но macOS часто не даёт ему ставить библиотеки).
2. Двойной клик по **`Запустить панель.command`**.
   macOS может ругаться на «неизвестного разработчика»: правый клик по файлу →
   «Открыть» → «Открыть».
   Из Терминала то же самое: `cd ~/Desktop/vk_feed_parser` и `python3 start_panel.py`.
3. Первый запуск скачает библиотеки и Chromium (~2–5 минут, нужен интернет),
   дальше панель поднимается за пару секунд.

### Windows

1. Поставьте Python 3.11 или 3.12 (галочка «Add python.exe to PATH»).
2. Двойной клик по **`Запустить панель.bat`** (или `start_panel.bat`).
   Если окно моргнуло и закрылось — из PowerShell в папке проекта:
   `.\start_panel.bat`

Панель должна открыться в браузере сама; если нет — адрес написан в окне запуска.

## 2. Порядок работы в панели

1. **Аккаунты** → «Добавить аккаунты…» → строка `телефон;пароль;2FA;прокси`
   (2FA и прокси можно не заполнять).
   У строки со значком «нет сессии» нажмите **«Войти в VK»**: откроется Chromium,
   пароль и код из SMS вводите в этом же окне. Повторите для каждого аккаунта.
2. «Проверить аккаунты» — статус должен стать «работает».
3. **Теги** → впишите хештеги (по строке, без `#` тоже можно) → «Добавить тег».
   Строки, начинающиеся с `# ` или `//`, — комментарии.
4. **Прогон** → период (часы), «потоков» = сколько аккаунтов задействовать → «Старт».
   Лог идёт внизу страницы, Excel `data/exports/vk_feed_live.xlsx` обновляется по ходу.
5. «Стоп» — то же, что Ctrl+C: прогресс остаётся в базе, следующий «Старт» продолжит
   с того же места. Прерванные окна доделываются автоматически.

## 3. Несколько аккаунтов (мультиаккаунт)

- `data/accounts.txt` — по строке на аккаунт: `телефон;пароль;2FA_СЕКРЕТ;прокси`.
  Порядок строк = номер аккаунта. Строки с `#` или `//` в начале — комментарии.
- Вход у каждого аккаунта свой: сессии лежат в `data/session.json` и
  `data/session_<телефон>.json`, профиль браузера — `data/vk_browser_profile_<номер>`
  (уже вошедший аккаунт использует свою прежнюю папку профиля). Входы друг другу не мешают.
  Кнопка «Войти в VK» в строке аккаунта — это
  `python3 src/vk_auth.py --login --account N`.
- Потоки: больше, чем живых аккаунтов, движок не запустит — в логе видно
  `аккаунтов 3 (готовы 1, отлёжка 0, мертвы 2), воркеров 1`.
  Воркеры не закреплены за аккаунтом: освободился — берут следующий живой.
- Капча/лимит → аккаунт уходит в «отлёжка» (от минуты до часа) и возвращается сам.
  «Мёртв» = нужен повторный вход («Войти в VK»).
- Прокси берётся из строки аккаунта, а если там пусто — из `proxies.txt`
  (строка с тем же номером, что и аккаунт). Слово `direct` (или `none`, `-`)
  вместо адреса значит работу без прокси. Проверка — кнопка «Проверить прокси».
- Колонка «Прокси» в таблице аккаунтов показывает то, что реально пойдёт в работу
  (из `accounts.txt` / `proxies.txt`); пусто («—») — это `direct`, вход напрямую.

## 4. Если что-то не так

| Симптом | Что делать |
|---|---|
| `python: command not found` (macOS) | команда называется `python3`; проще запускать `Запустить панель.command` |
| «Chromium не установился» | проверьте интернет и запустите панель снова (или `python3 -m playwright install chromium`) |
| Аккаунт «мёртв — токен не обновлён (нужен curl_cffi)» | запуск шёл Python без библиотек: запускайте через `Запустить панель.command` / `python3 start_panel.py` — он сам выберет подходящий Python |
| Аккаунт «мёртв — нет файла сессии» | нажмите «Войти в VK» в строке аккаунта |
| Вошли, а VK показывает QR-код | отсканируйте его приложением VK или просто подождите ~25 секунд — скрипт сам перейдёт к вводу телефона и пароля |
| Вход «висит» и панель не даёт нажать «Старт» | закройте панель и откройте заново (незавершённый вход она считает активным процессом) |
| Порт 8787 занят | панель сама возьмёт следующий порт и напишет адрес в окне |
| «нет tkinter» | это про старое окно (`Запустить окно.bat`); панель в браузере работает без него |
| Библиотеки не ставятся на Python 3.13/3.14 | поставьте 3.11 или 3.12: колёса `curl_cffi` есть не под все версии |
| Прогон застрял на старых окнах | «Стоп» и «Старт» заново; бросить недоделанные окна: `python3 src/run_tags.py --no-resume` |

## 5. Что где лежит

| Путь | Что это |
|---|---|
| `start_panel.py` | запуск «в один клик»: сам ставит библиотеки и браузер |
| `Запустить панель.command` / `.bat` | файлы для двойного клика (macOS / Windows) |
| `data/accounts.txt` | аккаунты (ваши данные) |
| `data/tags.txt` | хештеги |
| `proxies.txt` | прокси (в корне проекта) |
| `data/settings.json` | настройки панели |
| `data/parser.sqlite3` | база: посты, окна, статусы аккаунтов — **не удалять** |
| `data/exports/` | Excel с результатом |
| `data/session*.json` | сессии входа (доступ к аккаунтам — никому не передавайте) |
| `data/logs/` | скриншоты окон входа, когда что-то не сошлось (можно чистить) |
| `.venv/` | библиотеки проекта, если их ставила панель |
| `src/`, `tests/` | код и проверки |

## 6. Команды без панели (необязательно)

```bash
python3 src/run_tags.py --hours 24 --workers 3 --validate-first data/tags.txt
python3 src/run_tags.py --full              # пройти весь период, даже уже собранное
python3 src/run_tags.py --no-resume         # не доделывать прерванные окна
python3 src/vk_auth.py --login --account 2  # вход во второй аккаунт
python3 src/vk_auth.py --status             # чей вход сохранён
python3 src/account_pool.py --status        # работает / отлёжка / мёртв
python3 src/check_proxy.py                  # проверить прокси
python3 src/export_xlsx.py                  # выгрузить Excel
python3 src/webui.py --selftest             # самопроверка панели
```

На Windows вместо `python3` — `python`.
