КАК ЗАПУСТИТЬ — коротко
=======================

1. ЗАПУСК ПАНЕЛИ (двойной клик)
   Windows: «Запустить панель.bat» (или start_panel.bat)
   macOS:   «Запустить панель.command»
   Откроется браузер с панелью. Первый запуск ставит библиотеки и Chromium
   (2–5 минут, нужен интернет), следующие — сразу.
   macOS не даёт открыть файл? Правый клик → «Открыть» → «Открыть».

2. ВХОД В VK (для каждого аккаунта один раз)
   Раздел «Аккаунты» → «Добавить аккаунты…», строка вида
        +79990000000;пароль;;        (2FA и прокси можно не заполнять)
   → в строке аккаунта кнопка «Войти в VK» → откроется Chromium:
     пароль и код из SMS вводите в этом же окне.
   Готово, когда «Проверить аккаунты» показывает «работает».

3. СБОР ПОСТОВ
   Раздел «Теги» → впишите хештеги (по строке) → «Добавить тег».
   Раздел «Прогон» → период в часах и «потоков» (сколько аккаунтов сразу)
   → «Старт». «Стоп» = Ctrl+C: прогресс сохраняется, следующий «Старт»
   продолжит с того же места.

4. РЕЗУЛЬТАТ
   data/exports/vk_feed_live.xlsx — обновляется прямо во время сбора.

5. СТАТУСЫ АККАУНТОВ
   работает — аккаунт в деле
   отлёжка  — VK притормозил (капча/лимит), вернётся сам через 1 мин – 1 час
   мёртв    — нужен повторный вход: «Войти в VK» в строке аккаунта

6. ЕСЛИ ЧТО
   python: command not found (macOS)  → запускайте «Запустить панель.command»
   Chromium не установился            → проверьте интернет и запустите снова
   порт 8787 занят                    → панель сама возьмёт следующий (адрес в окне)
   «нет tkinter»                      → это про старое окно; панель в браузере не при чём
   Аккаунт «мёртв — нет файла сессии» → нажмите «Войти в VK»
   Подробнее (macOS и Windows)        → README.md

Пока открыто окно с адресом панели — панель работает.
Закрыть панель: Ctrl+C в этом окне.
